# 💿 Debian Hybrid TV-Desktop OS Builder (Live-Build + GitHub Actions)

Специализированная сборка на базе **Debian 12 Bookworm (64-bit)** для устройств с малым объемом оперативной памяти.

## 🚀 Основные особенности

* **Минимальное потребление ОЗУ**:
  * ~280–320 МБ в режиме рабочего стола.
  * Интегрирован **ZRAM** с алгоритмом `zstd` (сжатие оперативной памяти на 50% без износа диска).
  * Твики ядра для плавной работы при нехватке памяти (`sysctl low-ram`).
* **Два режима работы**:
  * **Режим ТВ-приставки (TV Box)**: 10-foot интерфейс на базе Kodi. Поддерживает работу с пультом/геймпадом и запуск **любых обычных программ Linux**, браузера и Wine прямо поверх интерфейса.
  * **Классический рабочий стол (Desktop)**: Легковесный XFCE с панелью задач, файловым менеджером Thunar и терминалом.
* **Выбор режима по умолчанию**:
  * В меню и на рабочем столе есть утилита **«Выбор режима (ТВ / ПК)»**, которая позволяет в один клик переключить, какой режим будет загружаться при старте устройства.
* **Встроенный Wine (64-bit + 32-bit Multiarch)**:
  * Предустановлены `wine`, `wine32`, `wine64`, `winetricks`, `cabextract` для запуска Windows-программ и игр.

## 🛠 Как собрать готовый ISO через GitHub (в 3 шага)

### Шаг 1. Создайте репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) и создайте новый пустой репозиторий (например, `debian-tv-desktop`).

### Шаг 2. Загрузите файлы в свой репозиторий
Откройте PowerShell в папке с этим проектом и выполните:
```bash
git init
git add .
git commit -m "Initial commit of Debian TV-Desktop OS builder"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/debian-tv-desktop.git
git push -u origin main
```

### Шаг 3. Запустите сборку
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Слева выберите воркфлоу **"Build Debian Hybrid TV-Desktop ISO"**.
3. Нажмите кнопку **"Run workflow"** -> **"Run workflow"**.
4. GitHub запустит виртуальную машину и за ~10–15 минут соберет чистый образ.

### 📥 Где скачать готовый ISO?
* После завершения сборки перейдите в выполненный запуск во вкладке **Actions**.
* Внизу в блоке **Artifacts** будет файл **`debian-tv-desktop-iso`** с готовым `.iso` внутри.
* *(Опционально)* Если вы создадите Git-тег (`git tag v1.0 && git push --tags`), GitHub автоматически создаст Release и прикрепит файл туда.

## 🎮 Использование на ТВ-приставке / ПК

1. Запишите полученный `.iso` на флешку с помощью **Ventoy** или **Rufus** (в режиме DD или ISO).
2. Загрузитесь с флешки на вашем устройстве (поддерживаются как UEFI, так и Legacy BIOS).
3. При первой загрузке запустится режим ТВ-приставки (или рабочий стол, если вы измените выбор).
4. Логин по умолчанию: `user` (автологин включен, пароль не требуется, пароль для `sudo` — `live`).
